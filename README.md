# MineLab Linux Installer
An installer for MineLab server mods on Linux, written in Rust.

## How to use
Open a terminal in the directory containing the mods folder and run the following command to download and execute the automated installer:

```sh
curl -sSf https://raw.githubusercontent.com/GOFNY/minelab-linux-installer/main/scripts/install.sh | sh
```
